# Wave 1 sample profile

Wave 1 contains **n = 9** responses. It is a convenience stakeholder-discovery sample. It is not statistically, industry, ecosystem, or population representative.

## Roles

| Reported role | Count | Share |
| --- | ---: | ---: |
| Software Engineer | 5/9 | 56% |
| Full-Stack Engineer | 2/9 | 22% |
| Data Scientist / AI / ML Engineer | 1/9 | 11% |
| Security / Software Supply Chain Engineer | 1/9 | 11% |

The sample includes relevant engineering perspectives but no respondent selected a platform or dependency-management title. Role labels do not establish responsibility or authority.

## Engineering experience

| Experience | Count | Share |
| --- | ---: | ---: |
| Less than 1 year | 3/9 | 33% |
| 1–2 years | 3/9 | 33% |
| 3–5 years | 3/9 | 33% |

No respondent reported more than five years in the supplied categories. This limits inference about mature enterprise dependency programs.

## Dependency-upgrade experience

| Experience | Count | Share |
| --- | ---: | ---: |
| Several upgrades | 3/9 | 33% |
| One or two upgrades | 4/9 | 44% |
| No direct prior upgrade | 2/9 | 22% |

Seven of nine respondents reported personally working on at least one dependency or package upgrade. Two answered later hypothetical/workflow questions without direct upgrade experience; their answers remain in the matrix but carry less weight for observed-workflow claims.

## Ecosystems represented

This multi-select item produced 6/9 Python selections, 4/9 Java selections, and 2/9 JavaScript selections. Percentages sum above 100% because respondents could select multiple ecosystems. No claim is made about ecosystem prevalence.

## Approximate repository scope

| Repositories/applications | Count |
| --- | ---: |
| One | 3/9 |
| Two to five | 4/9 |
| Six to ten | 1/9 |
| Not sure | 1/9 |

Five respondents reported a recent scope above one repository/application. This supports testing multi-repository work but does not establish a stable portfolio-investigator role.

## Follow-up willingness

One respondent selected Yes, four Maybe, and four No. Follow-up willingness is mixed. The committed dataset contains no contact method.
