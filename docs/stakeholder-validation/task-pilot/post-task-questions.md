# Pilot post-task questions

Ask these neutrally after recording the participant’s post-task intended action. Follow-up prompts may ask “What led you to that view?” without suggesting an answer.

1. What did you believe PULSE was telling you?
2. What, if anything, did you find trustworthy?
3. What, if anything, did you distrust?
4. Was anything ambiguous or easy to misinterpret?
5. What evidence would you need before acting?
6. Did the system make this investigation easier, harder, or unchanged? Why?
7. Did it change what you would investigate next, clarify the same action, or leave it unchanged?
8. Which information would you ignore, and why?
9. Was the candidate, review, or provenance detail useful, burdensome, both, or neither?
10. Where would this fit, if anywhere, in your existing workflow?
11. Who would investigate, who would review, and who would make the final decision?
12. What would stop you from using a system like this?
13. Which term or status would you rename, if any, and what meaning would you expect instead?
14. Is there any conclusion you think the interface invited but the evidence did not support?

Do not ask whether the participant “validated” PULSE or agrees with a predetermined conclusion.
