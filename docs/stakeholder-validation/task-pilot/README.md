# Bounded stakeholder task-validation pilot

**Preparation status: `PREPARED_NOT_EXECUTED`**
**G8: `PARTIALLY_VALIDATED`**
**Phase 8: `NOT_STARTED`**

This package prepares a purposive 1–3 participant study of the existing read-only PULSE investigation workflow. It contains no participant results, success rates, stakeholder acceptance, or gate change.

## Participant materials

- [Participant profile](participant-profile.md) — recruitment fit, applied without storing identity here.
- [Task objective](task-objective.md) — neutral bounded investigation question.
- [Task sheet](task-sheet.md) — seven tasks supplied during the session.
- [Post-task questions](post-task-questions.md) — neutral reflection prompts.
- [Privacy protocol](privacy-protocol.md) — anonymous IDs and prohibited data.

## Moderator-only materials

- [Case selection](case-selection.md) — frozen cases, snapshots, and rationale.
- [Moderator script](moderator-script.md) — non-leading session flow.
- [Observation rubric](observation-rubric.md) — explicit nonnumeric outcomes.
- [Ground-truth reference](ground-truth-reference.md) — governed interpretation; do not provide before the task.
- [Decision-effect template](decision-effect-template.md) — initial versus post-task action.
- [Session template](session-template.md) — blank record for a real session.
- [Gate criteria](gate-criteria.md) — evidence needed before any G8 reassessment.
- [Analysis plan](analysis-plan.md) — later reconciliation method.

The primary study surface is the existing local React/FastAPI/PostgreSQL workflow. Power BI is not mixed into this pilot because that would confound interface comprehension; it can be tested separately in a later, explicitly designed study.
