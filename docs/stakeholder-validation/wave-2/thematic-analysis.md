# Wave 2 cumulative thematic analysis

This coding applies the Wave 1 codebook to five new responses and then reports cumulative n = 14. Counts are respondents with at least one direct signal; multi-select responses may support several themes. Direct evidence and analyst interpretation remain separate. Confidence applies only to this convenience sample.

| Theme | Direct response evidence | Counter-evidence | Analyst interpretation | Confidence / limitation |
