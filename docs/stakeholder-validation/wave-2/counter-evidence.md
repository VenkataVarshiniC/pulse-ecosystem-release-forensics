# Wave 2 cumulative counter-evidence

Wave 2 preserves and expands the negative evidence required to constrain PULSE claims.

| Counter-evidence | Cumulative evidence | Constraint |
| --- | --- | --- |
| Existing tools may suffice | Three select tool sufficiency; every support rating is 3 or 4. | PULSE must demonstrate a specific incremental benefit. |
| Automation reliance is weak | Four would not rely on automated conclusions; lack of trust is a barrier for 9/14. | Usefulness cannot be presented as reliance or acceptance. |
| False positives remain costly | Eight report irrelevant alerts; five select false positives as a barrier. | Candidate count is not value; grouping and qualification remain required. |
| Human review can erase value | Four select review burden; only three require human review for trust. | Mandatory review of every result is unsupported. |
| Integration evidence is uneven | Integration barrier remains 5/14, all from Wave 1. | Integration cost is material but not consistently repeated. |
| Security and private data constrain breadth | Security/privacy 5/14; private-data limitation 3/14. | Private collection requires authorization and explicit unavailable states. |
| Results may not change decisions | Two select non-impact; no PULSE decision task occurred. | Decision utility remains unvalidated. |
| Problem frequency is uncertain | Two select low frequency; two cannot characterize insufficient-evidence frequency. | Recurring demand, urgency, savings, and ROI remain unsupported. |
| Affected-repository leadership weakened | It remains cumulative plurality at 5/14, but 0/5 additions chose it as most useful. | Product framing cannot rely on a single universally leading capability. |
| Follow-up commitment is limited | Yes 3/14, Maybe 4/14, No 7/14. | No stakeholder signoff or committed design partnership exists. |

Usefulness remains positive, but the additions strengthen skepticism more than adoption evidence. The defensible product claim remains bounded evidence support for investigation.
