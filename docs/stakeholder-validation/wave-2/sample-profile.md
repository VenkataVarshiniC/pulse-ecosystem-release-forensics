## Ecosystems and scope

Cumulative ecosystem selections were Python 9/14 (64%), Java 6/14 (43%), JavaScript 3/14 (21%), and .NET, Go, and Ruby 1/14 (7%) each. This was multi-select and is not prevalence evidence.

Cumulative repository scope was one repository 4/14, two to five 4/14, six to ten 1/14, eleven to twenty-five 1/14, more than twenty-five 1/14, and unsure 3/14. Seven respondents reported more than one repository; four reported one and three were unsure.

Cumulative follow-up willingness was Yes 3/14, Maybe 4/14, and No 7/14. The committed matrices contain no contact method.
