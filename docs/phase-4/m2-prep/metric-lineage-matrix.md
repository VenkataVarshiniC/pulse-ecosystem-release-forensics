# Metric-to-model lineage: all 23 Phase 4 contracts

N/D are numerator/denominator sources. All facts are filtered to one published analysis_snapshot_id and case version unless task/replay grain explicitly differs. Dimensions below abbreviate case (C), repository (R), release (L), source (S), rule (Rule) and lifecycle category (Cat). Every rate exposes counts and an unavailable reason; zero denominator is unavailable. Status follows [M1A computability](../baseline-analysis/metric-computability.md): C computable, P partial, U unavailable. The exact metric definitions remain in [metrics framework](../metrics-framework.md); this table defines proposed build lineage, not new values.

MET-003 is **evidence coverage**, not observed adoption. MET-007 is eligibility coverage, not recovery rate. MET-009 is reviewed-emitted acceptance, not recall or population precision. MET-013/015 allow multi-label reason overlap and label it. MET-020 needs a governed replay-audit input outside current core schema; that addition is an explicit future source contract, not implied by a dbt rerun. Human time saved, trust, actual adoption and recovery remain outside this 23-metric catalog and unavailable without their own sources/eligible populations.
