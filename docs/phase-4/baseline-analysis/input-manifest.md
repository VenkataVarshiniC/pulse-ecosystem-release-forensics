# Frozen analytical input set

This analysis reads **existing** Phase 2 public-evidence validation artifacts. [input-manifest.json](input-manifest.json) gives a SHA-256, path, case and role for every directly read local input and every external journal file used to freeze task evidence. The [analysis-only extractor](compute_baseline.py) verified source task identities and snapshot hashes, then wrote [frozen-task-audit.json](frozen-task-audit.json). The original raw snapshots remain in their external Phase 2 output roots and were **not copied or changed**. The compact audit makes subsequent baseline computation portable without those roots; re-extracting it requires those preserved paths.

Other direct inputs: `end-to-end-validation.json`, detector `metrics.json`, the two case reports' embedded collection coverage/historical paths/stage sufficiency/findings, and [replay-audit.json](replay-audit.json), recording two fresh verified reproductions of each case from frozen inputs. The external collector manifests/plans and all 54 `.attempt.json` records supply requirement, outcome, retry and capture method. The separate HTTPX Milestone 1 collector/resume run contributes 22 attempt records solely to the **MET-019 feasibility example**, not to either release-case denominator. Historical manifests are identity/lineage origins; baseline history counts come from the verified case reports. The input JSON lists all 82 external manifest/attempt origins with hashes.

**Grain:** case membership, run × task, exact-ref path observation, candidate, terminal candidate review, member × lifecycle category finding, and replay attempt. Candidate event time is not candidate emission time. Report `missing_sources` is repository-level, not a coded stage-specific reason. No new GitHub/PyPI outcome was retrieved; no synthetic or cherry-picked member was added. The two convenience cohorts cannot support ecosystem rates.

Recompute with `python docs/phase-4/baseline-analysis/compute_baseline.py`; the helper checks local input hashes. `--freeze` re-extracts the external original journals if present; `--verify-replay` invokes the existing frozen Phase 2 reproducer twice and records exact output hashes. These modes do not call external APIs or change PULSE collection behavior.
