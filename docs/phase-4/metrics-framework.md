# Product analytics metric contracts — design, not computed results

All rates are bounded to a **named case, frozen cohort, observation window, source plan and rule/report version**. Display the numerator and denominator beside a percent. Count distinct keys at the stated grain before aggregating. A zero denominator, missing prerequisite, or unreconciled identity yields **unavailable with reason**, never 0%. `UNKNOWN` is a finding/assessment state, not a negative event. Rates for different cases are shown separately unless methods and sampling frames are made comparable. Source entities below refer to the [Phase 3 logical model](../phase-3/logical-data-model.md), not implemented database tables.

Status key: **C** = currently derivable from bounded Phase 2 artifacts but not calculated by this design; **P** = partly observable or needs method/field completion; **F** = future source/workflow absent. `Stakeholder: none` means the technical definition is independent of user approval; business importance remains unvalidated. Each metric row states the decision question (`Q`), numerator (`N`), denominator (`D`), grain/dimensions (`G/Dim`), source (`Src`), exclusions (`Ex`), UNKNOWN/unavailable handling (`U`), interpretation/misuse (`Read`), and measurability/stakeholder dependency (`State`). All denominators are case-local unless expressly marked task/candidate.

## Evidence coverage and sufficiency

| Contract | Definition and decision question | Computation and grain | Controls and interpretation | State |
| --- | --- | --- | --- | --- |
| **MET-001 Repository Core Collection Coverage** | Q: where did planned core acquisition complete? N = members whose required metadata/issues/PRs/commits tasks completed under frozen plan; D = all declared members. G = case × repository; Dim = case, release, source plan. Src = membership, run/task. | Ex: no frozen member; optional verified 404 is complete, required failure is not. U: missing task outcome cannot count complete. Read: acquisition of planned sources only; **not** comprehensive discoverability or lifecycle evidence. | C; stakeholder: none. |
| **MET-002 Historical Context Coverage** | Q: where was a target-package declaration found at an exact ref? N = members with parsed exact-ref target declaration; D = declared members. G = case × repository; Dim = release, paired/after-only status. Src = membership, historical observation, artifact. | Ex: current-only declaration. U: unresolved history stays denominator but not numerator, with reason. Read: contextual evidence coverage, **not** release-time presence/adoption. Stronger pre-release paired-path coverage is a separate breakdown. | C; stakeholder: none. |
| **MET-003 Target-Version Evidence Coverage** | Q: where is a qualified resolved/installed target-version observation available? N = members with qualifying version plus ref/environment/time/provenance; D = declared members. G = case × repository; Dim = release, source/method. Src = target-version observation, artifact, membership. | Ex: permissive specifier, proposed PR diff, current declaration. U: absent qualified source = no evidence, not no adoption. Read: source coverage only, not an adoption rate. | F; stakeholder: source access/method and relevance to user decision pending. |
| **MET-004 Stage Source Completeness** | Q: which category's required source set was completely collected? N = member-stage pairs with every declared required stage source complete; D = all declared member-stage pairs for that category. G = case × repository × category; Dim = category, source, case. Src = source plan, task, assessment. | Ex: unplanned optional source cannot be silently counted complete. U: missing status or source plan = unavailable for affected category; incomplete pairs stay denominator. Read: source-plan completion **not** evidentiary sufficiency. | P; stakeholder: stage source set may change after evidence-method review. |
| **MET-005 Stage Evidence Sufficiency** | Q: for which category can the bounded finding rule be applied? N = member-stage assessments marked sufficient under versioned prerequisites; D = all declared member-stage pairs for that category. G = case × repository × category; Dim = reason, category. Src = assessment, history, task, review. | Ex: no membership. U: unknown/conflict/incomplete remains denominator, not numerator; missing assessment = unavailable for publishing rate until reconciled. Read: eligibility for a bounded answer, not event success. | P; stakeholder: question-specific threshold may change; integrity rules remain. |
| **MET-006 Investigation Outcome Coverage** | Q: how many members have a defensible repository-level output? N = declared members with all **declared required category questions** resolved to YES or bounded NO, with provenance; D = declared members. G = case × repository; Dim = case, unresolved reason. Src = membership, assessments, findings, report specification. | Ex: categories explicitly outside case scope, fixed before results. U: any required UNKNOWN or undefined case question set makes member not resolved; undefined set makes metric unavailable. Read: answer coverage, not favorable outcome or user task completion. | P; stakeholder: which questions constitute useful completion pending. |
| **MET-007 Recovery-Evidence Eligibility Coverage** | Q: for how many declared members can recovery even be assessed? N = members satisfying a versioned eligible event, source and window rule; D = declared members. G = case × repository; Dim = release, eligibility reason. Src = accepted finding, downstream source, assessment, membership. | Ex: PR merge alone; no implicit event/window. U: if eligible-set method not declared, **entire metric unavailable**. Read: evidence eligibility, not recovery rate. | F; stakeholder: meaning of recovery/completion pending. |

## Investigation and candidate path

| Contract | Definition and decision question | Computation and grain | Controls and interpretation | State |
| --- | --- | --- | --- | --- |
| **MET-008 Candidate Emission Coverage** | Q: where did rules produce review material? N = members with ≥1 frozen candidate; D = declared members. G = case × repository; Dim = rule, source, release. Src = membership, candidate baseline. | Ex: duplicates of same candidate ID. U: missing baseline identity makes rate unavailable. Read: detector activity, **not impact incidence**; 0 does not prove no event. | C; stakeholder: none. |
| **MET-009 Reviewed-Candidate Acceptance** | Q: among reviewed emissions, what qualified? N = accepted emitted candidate IDs; D = emitted candidate IDs with terminal accepted or rejected review. G = candidate; Dim = rule, source origin, case. Src = candidate, analyst review, artifact. | Ex: unreviewed/needs-more-evidence from D; duplicate terminal reviews block publication. U: D=0 unavailable. Read: reviewed-emitted precision proxy for this set only, not detector recall/population precision. | C; stakeholder: acceptance criteria may evolve by governed method. |
| **MET-010 Reviewed-Candidate Rejection** | Q: which rules generate nonqualifying review work? N = rejected candidate IDs; D = terminally reviewed emitted candidate IDs. G = candidate; Dim = rule, reason, source origin. Src = candidate, review. | Ex: unresolved; U: D=0 unavailable. Read: bounded rejection mix, not human hours or universal false-positive rate. | C; stakeholder: none for technical definition. |
| **MET-011 Unresolved Candidate Share** | Q: what remains pending review? N = emitted candidates without terminal decision, including NEEDS_REVIEW; D = all emitted candidates in frozen baseline. G = candidate; Dim = case, rule. Src = baseline, review ledger. | Ex: no emitted candidates; U: D=0 unavailable, missing ledger = unresolved only if baseline/ledger integrity verified. Read: review state, not evidence against an event. | C; stakeholder: resolution policy pending. |
| **MET-022 Candidate Density** | Q: where is review material concentrated? N = count of emitted candidate IDs; D = declared members; report as candidates/member (not percentage). G = candidate aggregated to case × repository; Dim = rule, source. Src = baseline, membership. | Ex: duplicate IDs; U: missing baseline unavailable. Read: work proxy, not event rate; disclose single-artifact clustering. | C; stakeholder: burden interpretation pending. |

G = run × task; Dim = source, case. Src = run, task. | Ex: optional tasks; U: missing task result remains D but not N, identity mismatch blocks report. N = optional planned tasks terminal `not_found`; D = all optional planned tasks with verified terminal outcome. G = run × task; Dim = source/path. | **MET-019 Verified Resume Reuse** | Q: how much work was reused in an actual resumed run? N = eligible tasks whose verified immutable prior result was reused; D = eligible tasks in a **documented resumed run**. G = resume run × task; Dim = source. ## Metrics intentionally unavailable now

**Observed adoption rate** requires a qualified target-version observation and a predeclared eligible population/time rule; current constraints or MET-002/003 coverage cannot substitute. **Recovery rate** requires qualifying accepted event, recovery-eligible set, observation window and downstream evidence; a PR merge is insufficient. **Detector recall** requires independent labels for emitted and non-emitted records. All remain unavailable on current Phase 2 evidence. **Manual time saved, user trust, usefulness, burden tolerance, priority quality and completion** remain `PENDING STAKEHOLDER / FUTURE PRODUCT VALIDATION`; no baseline or target is invented.

## Integrity checks before publication

Apply [RULE-001–014](../phase-3/business-rules.md): preserve frozen members, current-vs-historical distinction, candidate/review separation, rejected leakage prohibition, stage sufficiency, after-only boundary, recovery eligibility, identity chain and noncausal wording. A bounded `NO_QUALIFYING_EVIDENCE_FOUND` is **not** evidence the event did not occur. Technical changes to a metric require a versioned definition and side-by-side backfill; never silently replace UNKNOWN with NO or 0%.
