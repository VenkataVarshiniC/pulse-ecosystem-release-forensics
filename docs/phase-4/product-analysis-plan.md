# Future product analysis program

Each analysis is a **planned question**, not a result. Begin with frozen case definitions, source-plan audit, and [metrics](metrics-framework.md). Report counts before percentages, missingness, case-specific selection and plausible alternative explanations.

| Analysis | Output and decision use | Readiness and boundary |
| --- | --- | --- |
| Investigation pathway | F0/F1/F2/F3/F4/F5 spine plus optional candidate branch; locate acquisition/context/review/report gaps. | Phase 2 can support bounded descriptive fragments; no standard user-conversion interpretation. |
| Evidence coverage | Source-class and paired-history coverage by member/release; prioritize source-method experiments. | Exact-ref declaration is coverage, not target adoption. |
| Cohort comparison | Release/package and high/partial/insufficient evidence cohorts with raw denominators. | Two convenience cases are not representative; compare method availability rather than ecosystem outcomes. |
| Candidate quality | Rule/source-origin acceptance, rejection reasons, artifact concentration. | Two rejected firings from one artifact are too small for broad precision; recall unmeasured. |
| UNKNOWN diagnosis | Reason-coded category findings, missing-source contribution, conflict audit. | Missing source is not an observed negative; multi-reason overlap explicit. |
| Repository segmentation | Context/source/candidate patterns and evidence gaps per declared member. | No ranking of “impact” from a zero-candidate or UNKNOWN member. |
| Time | Release boundary, artifact event/capture, review timestamps separately; only defensible intervals. | No category chronology or causal attribution; no labor estimate. |
| Reliability | Required-task failures, optional not-found, actual retries, verified resume and replay. | Operational completion does not establish source sufficiency. |
| Recovery | Eligible-set/window and qualified downstream signal if later available. | Presently **unavailable**; PR merge is not production recovery. |

The analytical handoff is a case diagnostic with finding, provenance, uncertainty, next evidence question and alternative explanation—not a prescriptive recommendation before investigation. Value, prioritization and completion analyses await primary stakeholders and a measured baseline.
