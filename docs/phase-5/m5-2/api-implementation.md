# M5.2 FastAPI implementation

The bounded operational API lives in `src/pulse/api`. `app.py` owns HTTP, routes, CORS and error translation; `schemas.py` defines Pydantic request/response types; `service.py` assembles selected case views and sanitizes public locators; `repository.py` contains parameterized PostgreSQL reads; `review.py` contains the isolated-test DRAFT review gate; `config.py` reads local settings. There is no ORM, migration, collector, metric calculation, frontend or Power BI change.

Install with `uv sync --locked --all-groups`. Start the existing isolated PostgreSQL cluster, then run `uv run uvicorn pulse.api.app:app --host 127.0.0.1 --port 8000`. The lock includes FastAPI and Uvicorn. `/docs` and `/openapi.json` expose the generated contract. Validation also uses `fastapi.testclient.TestClient` without a serving process.

Configuration uses environment variables first, then the existing ignored root `.env`: `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER`, `PGPASSWORD`, and `PULSE_API_ENV` (default `local`). The application permits only the isolated `127.0.0.1:55432`/`pulse_local` cluster and `pulse_dev` or `pulse_test`; credentials are never returned in HTTP. GET connections use PostgreSQL `default_transaction_read_only=on`, a three-second connect timeout and a per-request context manager. SQL is parameterized. No client SQL, arbitrary filesystem path or source URL is accepted.

Normal reads are allowlisted to the exact two M4.1B published validation snapshot IDs and require a matching `core.publication_record` plus `PUBLISHED_VALIDATION` state. Every detail request supplies `snapshot_id`, and repository operations verify declared membership. Candidates, reviews, assessments, findings and artifacts are selected through snapshot bridge tables. `core`/`ingestion` power record-level views; Python does not recompute governed metrics. The current small cohort permits bounded joins/subqueries without caching infrastructure. A larger cohort would merit query-plan review.

The committed [OpenAPI export](../../../data/validation/m5-2-openapi.json) is regenerated by `uv run python scripts/export_m5_2_openapi.py` and verified by its `--check` mode. OpenAPI is contract evidence, not stakeholder validation. The API serves a local portfolio environment; local read access is not enterprise authentication. G8 remains `NOT_YET_VALIDATED`.
