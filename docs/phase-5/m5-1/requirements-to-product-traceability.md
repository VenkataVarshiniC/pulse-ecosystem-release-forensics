# Phase 3 requirements to M5.1 product traceability

The [formal text, priority and evidence status](../../phase-3/requirements-specification.md), [backlog](../../phase-3/requirements-backlog.md), and [acceptance criteria](../../phase-3/acceptance-criteria.md) remain authoritative. The “requirement intent” below is a concise restatement, **not a rewritten approval**. All 28 Phase 3 requirements are mapped; 22 Must and six Should. “Existing” means an evidenced core/report/mart behavior where stated, **never an implemented FastAPI or React screen**. `G8 pending` means application actor, wording and utility have no stakeholder validation. Integrity guards remain binding regardless of G8.

Screen keys: **L** list, **O** overview, **R** repository, **E** evidence explorer, **F** finding detail, **C** candidate review, **P** provenance detail. API names refer to [capabilities](api-capability-spec.md), not URLs.
