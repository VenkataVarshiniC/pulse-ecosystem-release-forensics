# M5.1 and bounded MVP out-of-scope register

Exclusions preserve the [Phase 3 solution boundary](../../phase-3/solution-boundary.md). They are not an invitation to implement technology for portfolio breadth. Revisit only with validated decision need, access policy, evidence and an explicit later milestone.

| Item | Reason / condition for reconsideration |
|---|---|
| AI, LLM classification, embeddings, RAG or chatbot | Rule/review provenance is the current trust model; no validated need or evaluation basis for probabilistic claims. |
| Ecosystem-wide repository discovery or impact estimates | Cohort is explicitly declared; current two cases/eight members are not representative. |
| Vulnerability scanning or generic SCA | PULSE investigates a declared release; it is not a scanner. |
| Dependabot/Renovate replacement or update-bot PR creation | Existing tools handle updates; PULSE reconstructs evidence afterward. |
| CI/CD execution, deployments or production recovery certification | External operational systems/criteria are outside current evidence and authority. |
| Predictive or composite risk score / automated organizational priority | No validated portfolio decision, factors, target or override burden. |
| Billing, subscriptions, marketplace, notification engine | No requirement or measured workflow value. |
| Enterprise RBAC, admin console, production multi-tenancy | One proposed investigator with conditional reviewer capability suffices for specification; authority policy remains open. |
| Cloud deployment, Kafka, Redis, Kubernetes, microservices | Local PostgreSQL and one FastAPI service are sufficient for the bounded application plan. |
| Mobile app | No validated mobile investigation job. |
| New collector, installed-version source, recovery source, conflict method | Evidence-method changes require their own governed validation; M5.1 does not reopen completed Phase 0–4 work. |
| Power BI dashboard or DAX implementation | M4.2 is intentionally deferred under its [frozen handoff](../../phase-4/m4-2/power-bi-build-handoff.md). |
| UI case creation, automatic attention override, durable investigation closure in MVP | Phase 3 UC-01/04/06 owner, need and criteria are not validated; existing typed cases can be read. |

No FastAPI route, React component, package installation, database migration or new evidence collection belongs to M5.1.
