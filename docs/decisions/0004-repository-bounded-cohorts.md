# ADR 0004: Make declared repository cohorts the analytical boundary

## Status

Accepted

## Decision

Every case declares an explicit or rule-based cohort, its rationale, and inclusion metadata before metrics are calculated. Reports must name the method and cannot call cohort values ecosystem rates.

## Consequences

Denominators are auditable and Phase 0's unsupported ecosystem-wide implication is removed. Results cannot be generalized beyond the declared cohort without a defensible sampling design.
