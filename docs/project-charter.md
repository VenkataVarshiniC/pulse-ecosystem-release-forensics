# Project charter

## Question

Can public data reconstruct an evidence-backed lifecycle from a major release through downstream adoption, migration friction, remediation, and ecosystem recovery?

## Phase 0 outcome

Produce three defensible reconstructions, including a pure-Python API migration and a tracker-free case; document missing evidence and failure modes; and decide **GO TO PHASE 1**, **PIVOT**, or **STOP**. A score helps prioritize cases; it never substitutes for source review.

## Success criteria

- A release timestamp and change surface are supported by primary sources.
- At least one downstream project has direct adoption evidence.
- Migration or breakage records link to preserved public sources.
- Remediation and later compatibility can be placed on a timeline.
- Every claim states its evidence strength and limitations.

## Out of scope

Product UI, production API, warehouses, vector search, LLM classification, graph infrastructure, streaming systems, and cloud deployment.
