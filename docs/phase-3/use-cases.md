# Provisional release-investigation use cases

Actors are **proposed roles**, not validated personas. These flows describe possible use of the [To-Be process](to-be-process.md), not observed practice, implemented screens, or UAT execution. The [requirements](requirements-specification.md) and [AC](acceptance-criteria.md) remain the formal baseline. All six cases require stakeholder reconciliation, especially ownership and review burden.

| UC | Actor; preconditions; trigger | Normal flow | Alternate / exception flow | Outcome; requirements; validation status |
| --- | --- | --- | --- | --- |
| UC-01 — Define release investigation | Proposed engineer/investigator; target release and candidate owned repositories known; consequential release or explicit request. | Declare package/version, boundary, cohort, window, and selection rationale; inspect frozen case before collection. | Empty or silently expanded cohort is blocked; unknown scope prompts human clarification. | Bounded case and denominator; BR-001, SR-001, FR-001. **Provisional** owner and trigger. |
| UC-02 — Review source and historical sufficiency | Proposed investigator/analyst; case and planned source inventory exist; collection completes or fails. | Inspect required/optional outcomes, exact-ref observations, missing anchors, and question-specific sufficiency reasons. | Optional 404 remains distinct from required failure; after-only history or conflicting states yields unresolved/UNKNOWN rather than a negative. | Evidence state and missing-source list; BR-002, SR-002/004, FR-002/004/005/006, NFR-004. **System basis supported**, user action provisional. |
| UC-03 — Review candidate evidence | Proposed analyst; immutable baseline and source artifacts exist; candidate emitted. | Inspect original artifact, text origin, rule rationale, and downstream context; record accept/reject/needs-more-evidence with reason. | Copied upstream text alone is rejected or left unresolved; broken provenance blocks acceptance. | Review ledger; BR-003, SR-003, FR-007/008, NFR-001/003. **Partial system basis**, review role/burden unvalidated. |
| UC-04 — Compare repository attention | Proposed cross-repository decision-maker; declared cohort and source/finding states exist; investigation needs triage. | View each repository's findings, gaps, and inspectable attention rationale; override a suggestion where warranted. | If portfolio triage is not a real job, omit this path; collection failure remains visible in cohort. | Human-owned attention decision; BR-004, SR-005, FR-011. **Provisional stakeholder-dependent**. |
| UC-05 — Produce bounded forensic report | Proposed investigator/reviewer; case, collection, history, review, and sufficiency artifacts are linked; report requested. | Generate stable repository and cohort findings with source coverage, accepted/rejected/unresolved evidence, denominator meanings, and UNKNOWN reasons. | Identity mismatch blocks release; no recovery eligibility keeps rate unavailable; zero candidates is not no event. | Reproducible report; BR-002/003, FR-009/010/012, NFR-001/002/003. **Current report basis supported**, future scope provisional. |
| UC-06 — Handle unresolved case and disposition | Proposed case owner, possibly distinct from reviewer; report contains missing/conflicting evidence or a local PR disposition; asks whether inquiry can close. | Inspect what is established, request more evidence or record bounded closure with unresolved items. | PR merged without installed/recovery evidence does not certify migration; no owner/criterion means disposition remains open. | Human next action; SR-004/006, FR-006/009/012. **Provisional stakeholder-dependent**. |

These cases do not assign production-risk authority to PULSE. A later respondent may confirm, merge, split, or reject any proposed actor or flow.
