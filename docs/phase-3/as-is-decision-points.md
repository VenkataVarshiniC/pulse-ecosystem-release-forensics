# As-Is decision-point catalogue

These are visible **local PR decisions** or unverified **broader investigation decisions**, not requirements or an approval policy. A PR can be merged without a public explanation, and an automated closure reply does not establish who made the underlying choice. Sources are [the frozen PR observations](secondary-research/github-pr-observations.jsonl), [Phase 2 findings](../phase-2/phase-2-findings.md), and [Milestone 1 hypotheses](primary-user-hypothesis.md). `Not visible` means the public record does not show a decision, not that nobody made one.

| ID | Decision and owner if known | Evidence used or visible | Outcome options and uncertainty | Source / validation status |
| --- | --- | --- | --- | --- |
| DP-01 | Accept a local package update; reviewer/maintainer visible only where approval or command is public. | PR diff, body context, optional review; [Couchers#5417](https://github.com/Couchers-org/couchers/pull/5417) shows approval plus merge command. | Approve/merge, request revision, or leave unresolved; check-run success was not systematically audited. | GH; `secondary-evidence-supported` as local action, not a general policy. |
| DP-02 | Retain an older proposed version; a visible maintainer comment in [uvicorn#2549](https://github.com/Kludex/uvicorn/pull/2549#discussion_r1900374580). | Inline suggestion and final dependency diff. | Retain pin versus upgrade; reason beyond the public suggestion is unknown. | GH; `secondary-evidence-supported` for one case. |
| DP-03 | Address a reported test/type-check issue; reviewers/contributor visible in [baseplate.py#1054](https://github.com/reddit/baseplate.py/pull/1054). | Test-failure review, downstream typing explanation, code/lockfile diff, later approval. | Change code, revise proposal, or close; private work and total effort unknown. | GH; `secondary-evidence-supported` for one case. |
| DP-04 | Close or supersede an update; underlying decision owner often not visible. | Explicit bot status such as [“Superseded by #1058”](https://github.com/reddit/baseplate.py/pull/1045#issuecomment-2573463429). | Merge, close without merge, supersede, or remain open; closure reason recorded only if explicit. | GH; `secondary-evidence-supported` for local disposition. |
| DP-05 | Ask Dependabot to rebase; human commenter visible in [Delphix#598](https://github.com/delphix/virtualization-sdk/pull/598#issuecomment-4136405732). | Public `@dependabot rebase` command and bot up-to-date reply. | Retry or no longer needed; completed rebase is not proved by the command alone. | GH; `secondary-evidence-supported` for command, not a universal path. |
| DP-06 | Decide which repositories need investigation after an upstream release; owner unknown. | A declared repository set would be needed; Phase 2 research cohorts do not show an organization's choice. | Prioritize, defer, or exclude are possible, **not observed**. | M1 hypothesis; `hypothesized`, `pending stakeholder validation`. |
| DP-07 | Decide whether remediation is required; owner and evidence threshold unknown. | PULSE candidate/review evidence is currently sparse; public PRs show local changes but not a portfolio decision. | Remediate, investigate further, or record uncertainty are possible, **not observed** as organizational decisions. | P2/M1; `hypothesized`, `pending stakeholder validation`. |
| DP-08 | Declare migration or production recovery complete; owner/criterion unknown. | PR disposition alone is insufficient; downstream releases and recovery eligibility absent in Phase 2. | Completion, ongoing work, or UNKNOWN cannot be assigned without a stakeholder definition and evidence. | P2/M1; `not observable`, `pending stakeholder validation`. |

Local PR disposition (DP-01–05) cannot be promoted into DP-06–08 by inference. See [the process catalogue](as-is-process-catalogue.md) and [primary-research questions](milestone-2-primary-research-questions.md).
