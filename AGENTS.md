# Engineering rules

1. Read `PROJECT_CONTEXT.md` before major architecture decisions.
2. Use real public data.
3. Never fabricate missing evidence.
4. Never manufacture resume metrics.
5. Preserve raw source evidence.
6. Keep raw, processed, and analytical data separate.
7. Prefer transparent methods before AI or ML.
8. Do not introduce technology only for resume value.
9. Use modular Python with type hints.
10. Add tests for critical logic.
11. Never commit secrets.
12. Explicitly document assumptions and limitations.
13. Do not make causal claims from observational evidence.
14. Do not implement later phases unless explicitly requested.
